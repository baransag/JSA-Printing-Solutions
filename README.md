# JSA Printing Solutions

Premium, immersive digital showroom and web presence for **JSA Printing Solutions**. Built with React, TypeScript, Three.js 3D WebGL printing simulation, and an editorial design system.

## Features
- **3D Printing Studio Hero**: Interactive 5-scene printing production sequence (Sticker Printing Press, Hang Tag Finishing, Printed & Woven Garment Labels, Business Cards Foil Stamping, Final Sticker Showcase).
- **Interactive Product Showcase**: Lightbox inspection and category filter for all 23 verified services and products.
- **Brand Identity**: Ivory, Antique Gold, Emerald Green, and Burgundy luxury color palette.
- **Craftsmanship Workflow**: 4-stage client workflow timeline.
- **Verified Contact Hub**: Direct click-to-call links for City Office, Marketing Office, and Contact Person in Faisalabad, Pakistan.
- **Responsive & Accessible**: Mobile navigation drawer, high-performance WebGL fallback, and reduced-motion compliance.

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
